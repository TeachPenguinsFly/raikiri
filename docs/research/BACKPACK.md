# Backpack — разведка 2026-09-20

## Главное: доступ решается публичным эндпоинтом, и он открыт

`GET https://api.backpack.exchange/wapi/v1/country` — **машиночитаемый список
стран, без авторизации**, 212 записей, обновлён 2026-07-21. Проверено мной
лично, не только агентом.

Заблокировано **семь** стран: Канада, Куба, **Кипр**, Иран, КНДР, Литва,
Новая Зеландия.

```json
{"countryCode":"BY","countryName":"Belarus","blocked":false,"sanctioned":false,"kycLevel":"basic-kyc-level"}
{"countryCode":"PL","countryName":"Poland","blocked":false,"sanctioned":false,"kycLevel":"basic-kyc-level-EU"}
```

**Фильтрует по резидентству, а не по гражданству.** В таблице стран нет поля
национальности; в пункте о допуске соглашения слово «citizen» не встречается
вовсе, формулировка — «not resident, located in or otherwise attempting to
access… from a Restricted Location»; первое поле KYC — страна проживания.
KYC обязателен для любой торговли, провайдер Sumsub, до 3 дней на ручную
проверку. Польше не требуется подтверждение адреса.

Кипр в бане — при том, что это родина их собственного лицензированного
юрлица. Показательно.

## Юрлица: лицензия настоящая, но смотрит не на тебя

- Биржу ведёт **Trek Labs Ltd** (BVI). Кошелёк Backpack — отдельный продукт
  **Blue Coral Inc.**
- Основатель Armani Ferrante (автор Anchor). CCO — **бывший генеральный
  юрисконсульт FTX International**; президент US — бывший комиссар CFTC.
- **Backpack EU = Trek Labs Europe Ltd, CySEC CIF 273/15** — подтверждено
  дважды: PDF политики конфиденциальности с их же правовой страницы и
  публичный реестр CySEC (дата лицензии 23.04.2015, рег. 335683). Дата 2015
  выдаёт переиспользованную лицензию: K-DNA Financial Services → FTX EU Ltd →
  Trek Labs Europe Ltd.
- **Но перпы идут не туда.** По Schedule A маржинальные услуги оформлены на
  `3-102-939537 SOCIEDAD DE RESPONSABILIDAD LIMITADA`, **Коста-Рика**. Лицензия
  VARA (Дубай) прямо не покрывает фьючерсы и маржу.
- Слова «CySEC», «MiFID» и «Cyprus» **не встречаются ни разу** на 252
  страницах операционной документации и в пользовательском соглашении; Trek
  Labs Europe Ltd не фигурирует в Schedule A вовсе. Бейджи живут только на
  маркетинговой главной.
- `eu.backpack.exchange` — то же приложение на поддомене, обслуживает **ту же
  книгу** (совпал id сделки, топ бида, соседний lastUpdateId). Один движок,
  один пул ликвидности. Регуляторная обёртка, а не отдельная площадка.

**Вывод по юрлицам: европейское юрлицо для нас не аргумент.** Оно не является
контрагентом по перпам. Но это и не нужно — доступ открыт по резидентству.

## Перпы

190 рынков: **103 PERP** (85 крипто + 18 перпов на акции — NVDA, TSLA, SPY) и
87 спот; плюс 194 предсказательных рынка, скрытых за `?marketType=PREDICTION`.
Всё котируется и рассчитывается в USDC.

**Фандинг почасовой** — `fundingInterval: 3600000` мс, переключён с 8 часов
**20.08.2025**. Это важно для доски: сравнивать почасовую ставку с
восьмичасовой без нормализации нельзя.

Комиссии Tier 1: **2 bp мейкер / 5 bp тейкер**, до 0/1.8 bp на VIP 5. Уровень
считается по максимуму из {стейк BP, объём за 30 дней, NFT} — то есть стейк
заменяет объём. Отрицательных мейкерских комиссий в таблице VIP нет.

**Ликвидность тонкая и сконцентрированная:** $155 млн в сутки всего, BTC —
63% от этого, выше $1 млн в сутки только **10 перпов**. Реальная торгуемая
вселенная — верхние 6–10 рынков, а не 85.

## Публичный API — весь открыт

REST `https://api.backpack.exchange`, WS **`wss://ws.backpack.exchange`** —
голый хост. (`/stream` это устаревший API до 2024 года; именно поэтому мой
ранний зонд по нему получил 400.)

Публичные эндпоинты **не требуют авторизации** — проверено без единого
заголовка: `/api/v1/depth`, `/trades`, `/trades/history`,
**`/api/v1/fundingRates`** (почасовые строки, limit 10000, отматывается до
марта 2025), `/api/v1/markPrices` (марк + индекс + текущий фандинг + время
следующего одним вызовом), `/markets`, `/ticker`, `/tickers`, `/klines`,
`/openInterest`, `/status`, `/time`.

Подписка: `{"method":"SUBSCRIBE","params":[...]}`, ответы обёрнуты
`{"stream":…,"data":…}`. Каналы: `depth.<symbol>` (и `depth.200ms/600ms/1000ms`),
`trade.<symbol>`, `markPrice.<symbol>` (несёт оценочную ставку в поле `f`),
`bookTicker`, `ticker`, `kline`, `openInterest` (60 с), `liquidation`.

**Лимиты: 2000 запросов/мин, 30/мин на исторические, 429.** Документированы
только в FAQ поддержки, в OpenAPI их нет, **заголовков с остатком лимита не
отдаётся вовсе** — значит свой счётчик обязателен.

## Риски

**Страхового фонда нет.** Ноль упоминаний «insurance fund» на 252 страницах.
Вместо него каскад: ликвидация по книге → бэкстоп-провайдеры →
**автоделеверидж прибыльных контрагентов**, исполняемый вне книги и невидимый
в свечах.

Для двуногой позиции это главный риск: **твою прибыльную ногу на Backpack
может закрыть ADL, и хедж на другой площадке останется голым.** Это не
теоретическая придирка, а способ, которым такая конструкция ломается.

Доступность 99,938–99,977% за 90 дней, ровно один сбой (16.07.2026, ~70–80
мин), но `status_reports: []` — разбор не публиковался ни разу. Взломов,
обобществлённых убытков и жалоб на вывод в первоисточниках не найдено.
Ежедневное доказательство резервов, проверяется OtterSec.

## Заметки для адаптера

- **Тормоз тейкера 100 мс** применяется к любому ордеру без `postOnly`,
  включая IOC; отмены освобождены. То есть `postOnly` на входной ноге и
  дешевле, и структурно предпочтительнее.
- **Смешивание приватного стрима с публичными в одном кадре SUBSCRIBE
  отвергает всю пачку** с ошибкой 4003 и молча не подписывает ни один
  публичный канал.
- **В документации формула фандинга содержит устаревшее деление на 8** с
  восьмичасовой эпохи, продакшн его не применяет. Считать керри по
  `/api/v1/fundingRates`, а не по формуле из доков.

## Вердикт: БРАТЬ

Сильнейший довод: вся маркет-дата открыта и не требует авторизации, включая
почасовую историю фандинга с марта 2025. Значит клиент можно написать и
полностью проверить **до** любой попытки KYC — инженерный риск отвязан от
риска допуска. Сам допуск благоприятен: ни Беларусь, ни Польша не в списке из
семи, фильтр по резидентству.

Цена вопроса, которую надо держать в уме: контрагент по перпам — костариканское
ООО; ADL может закрыть прибыльную ногу вне книги; ликвидность тонкая.

## Не установлено

- Принимает ли Sumsub польскую карту побыту как основной документ и как
  трактуется белорусский паспорт при заявленном польском резидентстве.
  Списка принимаемых документов Backpack не публикует.
- Обязательная ли миграция европейских пользователей на Backpack EU.
- Потолки плеча для розницы ЕС (функции начальной маржи одинаковы на обоих
  хостах API — довод против отдельного европейского режима).
- Состав и веса бирж в индексной цене; единицы полей
  `fundingRateLowerBound/UpperBound`; причина сбоя 16.07.2026.
